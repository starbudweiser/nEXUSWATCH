# Changelog — nEXUSWATCH

Notes de version / release notes (EN + FR). Translations in IT and ES: see the Nexus Mods page.

## 1.4.0

**English**

- New optional Discord module (read-only): new threads from your server's forums, unread counts, threads without a reply from the server owner, forum tags, "Reply on Discord" button.
- Bot setup from the settings: Application ID builds the invite link, secure token field (stored in the Keychain), connection test, per-forum choice.
- One quiet summary notification (no sound) per refresh; the first load is silent.
- The module is hidden until a bot token is saved; it never writes to Discord.

**Français**

- Nouveau module Discord facultatif (lecture seule) : nouveaux fils des forums de votre serveur, non-lus, fils sans réponse du propriétaire du serveur, étiquettes, bouton « Répondre sur Discord ».
- Création du robot depuis les réglages : l'Application ID fabrique le lien d'invitation, champ sécurisé du jeton (rangé dans le Trousseau), test de connexion, choix des forums.
- Une seule notification récapitulative discrète (sans son) par actualisation ; le premier chargement est silencieux.
- Le module reste invisible tant qu'aucun jeton n'est enregistré ; il n'écrit jamais sur Discord.

## 1.3.0

**English**

- Signed with a Developer ID and notarized by Apple: macOS now opens the app without a security warning.
- Version number aligned across the Skyrim Mac Toolkit.
- Stats cards stay on one line: long labels end with « … » instead of wrapping.
- The "already watched" message names the mod concerned.
- A mod that is not published yet gets its own message instead of a connection error.

**Français**

- Signée avec un certificat Developer ID et notarisée par Apple : macOS ouvre désormais l'appli sans avertissement de sécurité.
- Numéro de version commun à tout le Skyrim Mac Toolkit.
- Cards de stats sur une ligne : les libellés trop longs se terminent par « … » au lieu de passer à la ligne.
- Le message « déjà suivi » nomme le mod concerné.
- Un mod pas encore publié a son propre message au lieu d'une erreur de connexion.

## 1.1.1

**English**

- Requests to the Nexus API now send Application-Name and Application-Version, as the API policy requires.
- New-version notice: the app checks the latest GitHub release once a day and offers to open the Nexus page, remind you later or skip that version. Nothing is downloaded or installed.

**Français**

- Les requêtes vers l'API Nexus envoient maintenant Application-Name et Application-Version, comme l'exige la politique de l'API.
- Avertissement de nouvelle version : l'appli consulte la dernière release GitHub une fois par jour et propose d'ouvrir la page Nexus, de rappeler plus tard ou d'ignorer cette version. Rien n'est téléchargé ni installé.
